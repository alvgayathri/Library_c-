# Library Management System
A simple console-based C++ project using object-oriented principles to manage a library's book collection.

## Features
- Add new books with ID, title, and author
- Display all books in the library
- Search for a book by title

## How to Run
1. Compile the program using any C++ compiler.
2. Run the executable and follow the menu options.
